## 维护规则

1. 只以厂商官方模型/价格页面为来源；第三方渠道的模型别名不写入 provider catalog。
2. 新模型先进入快照并标记 `active`，但没有官方价格时保留为待确认，不填零价格。
3. 官方下线、弃用或停止服务的模型标记 `deprecated`，不删除历史记录。
4. 价格变化通过新的 versioned migration 发布，不直接修改线上数据库。
5. 每次刷新后检查 provider、model、price component 的数量变化，并保存本报表。
