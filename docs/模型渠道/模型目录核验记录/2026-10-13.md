## 未处理项

OpenAI 官网同时展示历史 API 价格和多种快照/别名；只有生命周期页明确列出的型号才标记 deprecated，未将历史价格表中的所有旧型号批量下线。其他供应商的需要鉴权的模型列表 API 未作为公开证据使用，避免把渠道私有模型或未验证价格写入官方目录。

Qwen 新目录中的音频模型使用字符、音频时长或音频/文本分维度计量，Embedding/Rerank 使用独立端点；当前 Router 的阿里适配器和统一计费元数据还不能完整表达这些条件，因此保留在核验记录中，待端点和价格组件设计完成后单独 migration。
